# 생활습관 맞춤 추천과 기록

## 사용 흐름

챌린지에서 생활 상황, 활동 조절 필요 여부와 단 음료 습관을 고르면 음료·식사·활동에서 한 가지씩 제안한다. 후보 25개는 음료 7개, 식사 10개, 활동 8개다. 같은 영역에서 더 잘 맞는 후보를 고르거나 다른 조합을 볼 수 있다. 카드에는 언제 시작할지, 무엇을 한 번 할지, 완료 기준, 여건이 맞지 않을 때의 대안과 출처를 담는다.

| 상황 | 미션 예시 |
| --- | --- |
| 직장에서 오래 앉아 있음 | 업무가 끝나는 때에 안전한 실내에서 잠깐 움직이기 |
| 외식이 잦음 | 주문 화면에서 먹을 수 있는 채소 반찬을 미리 고르기 |
| 단 음료를 자주 주문함 | 자주 주문하는 음료의 무가당 옵션을 한 번 선택하기 |
| 움직임이 부담되거나 최근 활동에 불편을 기록함 | 다음에 이용할 수 있는 익숙한 평지나 실내 경로를 한 곳 미리 정하기 |

## 추천 규칙

1. 기존 건강정보 처리 동의, 이용 대상, 긴급 신호·당뇨병 진단과 미확인 의료 안내를 먼저 확인한다. 이용 제한 시 새 미션을 시작할 수 없다.
2. 선택한 장소와 실천 난이도에 맞는 후보만 남긴다. 활동 가능 여부를 모르거나 평소 운동을 하지 않으면 가벼운 활동까지 제안한다. 활동 조절이 필요하다고 답하거나, 선택해 반영한 기록에 활동 제약 신호 또는 최근 7일의 활동 불편 기록이 있으면 움직임 없이 완수하는 준비 미션만 제공한다.
3. 이용자가 ‘최근 건강기록 반영’을 선택한 경우, 90일 이내 본인의 최신 기록에서 평소 활동 여부와 기록된 관련 건강 상태를 참고한다. 혈압 관리 기록은 수치 목표 대신 영양표시와 주문 선택 후보에 반영한다. 14일 이내의 최근 수면 어려움 기록은 기억하기 쉬운 일과에 활동 준비를 붙이는 데만 쓰인다.
4. 이용자가 ‘최근 실천기록 반영’을 선택한 경우, 최근 28일의 본인 완료·미완료 이유를 날짜 단위로 읽는다. 같은 행동을 여러 날 실천했으면 다시 제안한다. 시간 부족·목표 부담이 반복되면 쉬운 준비를, 장소가 맞지 않으면 어디서든 가능한 후보를, 자주 잊으면 기존 일과에 붙이는 방법을 보여 준다.
5. 해당하는 조건의 점수를 합산해 영역별 후보를 정렬하고, 첫 조합에는 영역별 상위 후보를 넣는다. 다른 조합을 누르면 가능한 선택지를 순환한다. 위험 점수, 나이, 체중, 가구 소득 등은 운동량이나 음식·수분 양을 계산하는 데 쓰지 않는다. 점수와 기간은 운영 검증 대상으로 정한 제품 기준이다.

## API·기록·보상

- `POST /api/v1/challenge-recommendations/personal`에 `context`, `mobility`, `sweet_drinks`, `difficulty`, `use_health_record`, `use_activity_history`, `rotation`을 보낸다. 기록 반영은 각각 기본 해제이며 권한이 필요한 응답은 캐시하지 않는다. 선택 입력을 URL이나 DB에 저장할 필요 없이 추천과 시작 요청에서 전달한다. 응답에 원래의 건강값과 미실천 메모를 포함하지 않는다.
- `POST /api/v1/challenge-cycles`에서 `catalog_version: personal-v4`와 선택한 세 ID를 받는다. 같은 입력으로 후보의 적합성을 다시 확인하고, 한 사용자에게 진행 중인 사이클을 중복으로 만들지 않도록 사용자 행을 잠근다.
- 네 주 동안 사용자가 고른 미션을 유지한다. 완료는 날짜별로 직접 체크하며, 사진·위치·섭취량 입력 없이 기존 오늘 기록과 주간 리포트에 연결한다. 대안이 준비 행동이라면 그 행동을 완료한 것으로 기록한다. 다음 조합에 지난 실천을 반영한다.
- 기존 일일 당근 지급 경로를 사용한다. 날짜와 사용자에 묶인 보상 키로 재시도나 중복 제출을 처리한다. 맞춤 기록의 완료는 행동에 대한 자기보고다.
- 참고 문헌의 범위와 행동별 근거는 [생활습관 챌린지 근거 검토](./CHALLENGE_PERSONALIZATION_EVIDENCE.md)에 적었다. 출시 후에는 처음 3일 내 첫 기록률과 첫 기록 뒤 7일 이내 다른 날의 재실천율을 확인한다.
